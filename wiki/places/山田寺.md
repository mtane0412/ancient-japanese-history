# 山田寺

山田寺（法号は浄土寺）は、[[蘇我倉山田石川麻呂]]が舒明天皇13年（641年）に造営を始めた飛鳥の寺院で、石川麻呂の変（649年）による中断をはさみ、天武天皇14年（685年）に丈六仏が完成した（[[奈良文化財研究所-山田寺の沿革]]）。寺跡（奈良県桜井市）は特別史跡で、発掘調査によって7世紀に創建された寺院のほぼ全容が明らかになり、倒壊した状態で出土した東面回廊で知られる（[[文化庁-日本遺産山田寺跡]]、[[奈良文化財研究所飛鳥資料館-山田寺跡史跡指定100周年]]）。

## 史料に書かれていること

### 造営の経過（『上宮聖徳法王帝説』裏書）

『日本書紀』が山田寺に触れる箇所は少なく、造営過程の主な手がかりは『[[上宮聖徳法王帝説]]』の裏書である。裏書は年紀をすべて干支で記し、説話的な内容を含まないことから、家永三郎は685年をあまり降らない時期の確実な記録とみており、寺崎保広もこれを認める（[[奈良文化財研究所-山田寺の沿革]]）。裏書による経過は次のとおりである（干支の西暦換算は寺崎による）。

| 年 | 裏書の記事 |
|---|---|
| 641年（辛丑） | 浄土寺の地を平らす（3月15日に造営開始とする「有本」の記事もある） |
| 643年（癸卯） | 金堂を立てる |
| 648年（戊申） | 初めて僧が住む |
| 649年（己酉）3月25日 | 大臣（石川麻呂）が害に遇う |
| 663年（癸亥） | 塔を構える |
| 673年（癸酉）12月16日 | 塔の心柱を建て、心礎の円穴に「浄土寺」と刻み、舎利8粒を納める |
| 676年（丙子）4月8日 | 露盤を上げる |
| 678年（戊寅）12月4日 | 丈六の仏像を鋳る |
| 685年（乙酉）3月25日 | 仏眼を点じる |

- 649年3月25日の石川麻呂の死の日付は『書紀』と合致する（同上）。
- 寺崎は、663年の「塔を構える」は塔の位置を定めたことで、中断の後に673年に工事を再開したとみる。685年3月25日の開眼は石川麻呂の37年目の命日にあたる（同上）。
- 『書紀』によれば、天武天皇は685年8月に浄土寺に行幸した（同上）。
- 寺崎は浄土寺と山田寺を同じ寺とみる（別の寺とする説もある）（同上）。

### 石川麻呂の変と山田寺

- 『書紀』大化5年（649年）3月条によれば、讒言を受けた石川麻呂は難波から大和へ逃れて山田寺に入り、自害した。長子の興志は大和の山田の家で寺の造営を続けていたという（[[奈良文化財研究所-山田寺の沿革]]、[[蘇我倉山田石川麻呂]]）。

### その後の山田寺

- 文武3年（699年）に30年を限って封戸300戸を賜り、天平11年（739年）に石川年足が大般若経を浄土寺に置いた。治安3年（1023年）には藤原道長が参詣した（[[奈良文化財研究所-山田寺の沿革]]）。
- 文治3年（1187年）、興福寺東金堂の衆徒が山田寺講堂の丈六薬師三尊を奪い去り、東金堂の本尊とした（『玉葉』）。この像は応永18年（1411年）の火災で頭部を残して失われ、焼け残った仏頭は再建された東金堂本尊の台座の中に納められて忘れられたが、昭和12年（1937年）の東金堂解体修理の際に見つかった。現在、興福寺国宝館にある「山田寺仏頭」である（同上）。寺崎は、1187年の乱入時に山田寺は焼き打ちにあった可能性が高いとする（同上）。

## 考古学的に確認されていること

- 1982年からの発掘調査で、東面回廊が倒壊した状態で土に埋もれて見つかった（[[奈良文化財研究所飛鳥資料館-山田寺跡史跡指定100周年]]）。出土した回廊は、わが国最古の木造建築様式を示すとされる（[[文化庁-日本遺産山田寺跡]]）。
- 山田寺の下層整地土から出土した須恵器は、造営開始（641年頃）との関係から、最も新しい一群が640年頃と位置づけられ、7世紀の須恵器の年代を考える基準資料の一つとして用いられている（[[高橋照彦-阿武山古墳小考]]）。
- 寺跡は1921年に史跡に指定された（[[奈良文化財研究所飛鳥資料館-山田寺跡史跡指定100周年]]）。

## 諸説・論点

- **造営の中断**: 裏書の年紀には、塔（663年→673年）や丈六仏（678年→685年）で間隔があり、寺崎は中断や長期の工事と解する（[[奈良文化財研究所-山田寺の沿革]]）。中断の理由を石川麻呂の変や政局と結びつける議論があるかどうかは、本 Wiki では未整理である。
- **伽藍配置・発掘成果の詳細**: 奈良文化財研究所の発掘報告書（『山田寺発掘調査報告』）の本体（伽藍配置・遺構）は、本 Wiki では沿革の章のみを取り込んでいる。
