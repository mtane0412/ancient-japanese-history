# 大平山元遺跡

大平山元遺跡は、青森県外ヶ浜町にある[[旧石器時代]]末から[[縄文時代]]草創期への移行期の遺跡で、北東アジア最古級とされる無文土器が出土したことで知られる（[[縄文遺跡群公式サイト-縄文文化と構成資産]]）。[[北海道・北東北の縄文遺跡群]]では、定住の開始を示す最初の段階（ステージⅠa）に位置づけられている（同上）。

## 詳細

### 立地と遺物（考古学的に確認されていること）
- 陸奥湾に注ぐ蟹田川沿岸の、標高26mの河岸段丘上に立地する。サケ・マスが遡上する川の近くで、良質な石材が得られる場所である（[[縄文遺跡群公式サイト-縄文文化と構成資産]]）。
- 旧石器時代の終わりごろの特徴を持つ石器群とともに、土器片と石鏃が出土した。土器は縄の施文や貼り付けなどの装飾がない無文土器である（同上）。
- 柱穴や凹み、地下への掘り込みは認められていない（同上）。

### 解釈
- 公式サイトは、土器片の分布から土器を中心とした居住空間を想定し、住居は移動式テントのようなもので、最小限の土地利用で自然環境に適応した生活を送っていたと「考えられる」とする（[[縄文遺跡群公式サイト-縄文文化と構成資産]]）。
- 土器の出現を定住生活の始まりの指標とみなし、旧石器時代の移動生活から縄文時代の定住生活への移行を示す証拠と位置づけている（同上）。

## 諸説・論点

### 土器の年代
大平山元遺跡の土器の年代は、同じ測定データの評価の仕方と、使う較正曲線によって異なる。

| 論者・資料 | 年代 | 根拠 |
|---|---|---|
| 谷口康浩（1999） | 16,000年前を越える（1999年の報道では約16,500年前） | 5点の測定値のうち、汚染が最も少ないと考えた最古の値を重視し、IntCal98で較正（[[小林謙一-縄紋時代前半期の実年代]]による紹介、[[工藤雄一郎-土器出現の年代と古環境]]） |
| 小林謙一（2007） | 約15,500年前（または約15,700年前） | 微量試料では鉱物起源の古い炭素が混じり古く出る場合があるとして、平均的な値を較正（[[小林謙一-縄紋時代前半期の実年代]]） |
| 工藤雄一郎（2012） | 15,000年前より遡ると考えるのが整合的。土器出現全体は17,000〜15,000年前のどこか | IntCal09で較正し直すと確率分布が古いほうにずれ、幅も大きく広がる（「13,000年問題」）。考古学的編年も考慮（[[工藤雄一郎-土器出現期の較正年代]]） |
| 縄文遺跡群公式サイト | 紀元前13,000年頃の可能性（約15,000年前） | 土器付着炭化物の放射性炭素年代測定（[[縄文遺跡群公式サイト-縄文文化と構成資産]]） |

- 測定値は14C年代で13,780±170〜12,680±140 BP（同一個体の5点、平均13,070±440 BP）である（[[小林謙一-縄紋時代前半期の実年代]]）。
- ⚠️ 資料間の食い違い: 上の値は最大で1,000年以上離れている。詳細は [[縄文時代の始まり（土器出現年代）]] に整理した。
- 較正曲線の改訂の影響: 工藤（2012）は、IntCal04からIntCal09への更新で、この年代域（14C年代で13,000 BP前後）の較正年代が最大500年程度古くなり、しかも較正曲線が平らなため100年単位での絞り込みができなくなったと指摘した（[[工藤雄一郎-土器出現期の較正年代]]）。
- IntCal20（2020年公開）による再較正: 本 Wiki の調査（2026-10-09）では、大平山元Ⅰ遺跡の測定値そのものをIntCal13・IntCal20で較正し直した数値を示す資料は確認できなかった。IntCal20を用いた工藤ほか（2021）は、隆起線文土器の年代域ではIntCal13とIntCal20の差はほとんどないとし、隆起線文土器の最古段階が約16,000年前まで遡るなら、それに先行する大平山元Ⅰ遺跡などの無文土器群とほとんど時間差がないことになる、と述べるにとどまる（[[工藤雄一郎ほか-百人町三丁目西遺跡隆起線文土器の年代]]）。
- 再調査（2026-10-11）: 外ヶ浜町・青森県・世界遺産公式サイトの資料、Radiocarbon 誌の論文要旨、機関リポジトリを探したが、IntCal20 で較正し直した値は見つからなかった。確認できたのは次の2点である。(1) 測定値の初出報告（Nakamura ほか2001）は、土器付着炭化物5点が12,680〜13,780 BP で、較正は INTCAL98 であり、IntCal20 の値ではない（[[Radiocarbon誌-大平山元I遺跡出土土器付着炭化物の14C年代]]）。(2) 世界遺産公式サイトの2024年のチラシは「15,000年以上前」とするが、測定値と較正曲線は示していない（[[縄文遺跡群公式サイト-大平山元遺跡展示施設むーもん館チラシ]]）。IntCal20 の再較正値は、本Wikiでは未解決のままとする。
- 再々調査（2026-10-11、第4弾）: Web 検索で「大平山元」と IntCal20・再較正・2021年以降の年代再検討を組み合わせて探し、英語の文献（Radiocarbon 誌など）も探したが、大平山元Ⅰ遺跡の測定値を IntCal20 で較正し直した値を公表した資料は見つからなかった。青森県立郷土館の杉野森淳子・齋藤岳「外ヶ浜町大平山元Ⅰ遺跡出土土器」（『青森県立郷土館研究紀要』48号、2024年）は、同館が1975・1976年に発掘した無文土器片を再報告し、内面に炭化物が付着した破片があることを記すが、年代測定値や較正年代は示していない（本文を確認。資料メモは作成していない）。本Wikiでは、この課題を引き続き未解決とし、本Wiki自身による再較正は行わない（公表値ではないため）。
- 第5弾調査（2026-10-12）: 英語の検索語（"Odai Yamamoto" と IntCal20・calibrated・2022〜2024年）で再度探したが、見つかったのは IntCal98 で較正した初出報告と2000年代の再検討だけで、IntCal20 による再較正値を公表した資料は見つからなかった。
- 第6弾調査（2026-10-12、最終確認）: 日本語（「大平山元」と「IntCal20」の完全一致）と英語（Odai Yamamoto と IntCal20・recalibrated）で再度探したが、IntCal20 で較正し直した値を公表した資料は見つからなかった。見つかるのは IntCal98 による初出報告とその引用だけである。5回の調査で見つからなかったことから、本Wikiでは「IntCal20 による再較正値は、少なくともオンラインで参照できる形では公表されていない」と判断し、この課題を持ち越しとする（未公表なのか、紙媒体の報告にのみあるのかは確認できていない）。

### 「縄文時代」に含めるか
- 石器群は旧石器時代末の特徴を持ち、住居は移動式と考えられている。土器の出現をもって縄文時代とするか、定住化や隆線文土器の普及をもって縄文時代とするかによって、本遺跡の時代区分上の扱いは変わりうる（[[縄文時代の始まり（土器出現年代）]]）。
