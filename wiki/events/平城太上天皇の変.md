# 平城太上天皇の変

平城太上天皇の変（薬子の変）は、弘仁元年（810）9月、平城上皇が平城京への遷都を命じたことを発端に、上皇側と嵯峨天皇側が衝突した政変である（[[西本昌弘-薬子の変とその背景]]）。嵯峨天皇側が機先を制し、上皇側の蜂起は未然に防がれた。

## 詳細

### 経過（『日本後紀』に基づく整理）

西本昌弘の整理によれば、変の経過は次のとおりである（[[西本昌弘-薬子の変とその背景]]）。

1. 弘仁元年（810）9月6日、平城太上天皇が平城京への遷都の命令を出した。
2. 嵯峨天皇は坂上田村麻呂・藤原冬嗣・紀田上らを造宮使に任命した。
3. 平安宮の嵯峨天皇側は、上皇側近の藤原薬子・仲成を非難する詔書を出し、平城派官人の衛府や国司の任を解いて辺遠の国へ左遷し、自派の官人で衛府と要衝国を固めた。伊勢・近江・美濃の国府と故関に遣使して固関した。
4. 上皇側は畿内と紀伊国の兵を徴発し、東国へ向かおうとしたが、嵯峨天皇側によって蜂起は未然に防がれた。

### 背景（西本昌弘の解釈）

- [[桓武天皇]]は死去の際、安殿（平城）・神野（嵯峨）・大伴の三親王が各10年ずつ統治すべきことを遺勅した、と西本は推定する。
- 平城はこれを破って第三子の高岳親王を皇位につけようとし、神野親王の廃太子を計画したが失敗し、3年ほどで譲位した。変の遠因はこの皇位継承問題にあり、平城の即位前後から平城派と嵯峨派の官人の対立が始まっていたとする。
- 平城上皇や薬子・仲成にとって、王都・王統に関する桓武の構想は否定すべきものであり、それゆえ高岳立太子を実現し平城遷都を計画した。変は「桓武の構想を肯定するか否定するかの戦い」であった、と西本は結論する（[[西本昌弘-薬子の変とその背景]]）。

## 諸説・論点

### 呼称と主導者をめぐる論争

| 説 | 主な論者 | 内容 |
|---|---|---|
| 薬子・仲成主導説（旧説） | 川上多助 | 平城譲位で権勢を失った薬子・仲成が、上皇の健康回復に乗じて上皇の再即位を図った |
| 政治方針対立説 | 門脇禎二 | 律令体制の原則的施行を目指す平城上皇側と、それに反対する嵯峨天皇側の対立が規定的要因 |
| 式家勢力挽回説 | 大塚徳郎 | 藤原式家による勢力挽回の政変と位置づける |
| 平城上皇主体説（近年の定着しつつある見方） | （西本は研究動向として紹介） | 上皇の主体性を評価し、「平城太上天皇の変」と呼ぶべきとする |
| 西本昌弘説 | 西本昌弘 | 上皇の主体性は否定できないが、薬子・仲成の中心的役割も認めるべき。両者は矛盾しない |

（以上、[[西本昌弘-薬子の変とその背景]]による研究史整理）

- 西本は、薬子らの父[[藤原種継]]の復権・顕彰が図られた事実や、薬子・仲成の係累が変の後も長く許されなかった事実から、薬子・仲成が中心的役割を果たしたことを認めないわけにはいかないとする（[[西本昌弘-薬子の変とその背景]]）。
- 呼称について、本Wikiでは近年の研究動向を踏まえて「平城太上天皇の変」を見出しとし、「薬子の変」を別名とする。
