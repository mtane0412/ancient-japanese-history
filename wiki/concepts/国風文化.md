# 国風文化

国風文化は、一般に10〜11世紀を中心とする日本的な貴族文化を指す用語である。しかし、「遣唐使の廃止によって中国文化が入らなくなり、日本独自の文化が生まれた」という従来の説明は現在の研究では否定されており、用語そのものの成立事情や定義をめぐって議論が続いている（[[水口幹記-国風文化論の現在]]）。本Wikiでは平安時代前期からの連続性の観点で扱う。

## 詳細

### 用語の成立史

- 吉川真司によれば、中学校教科書に「国風文化」という用語が初めて登場したのは1937年発行の渡辺世祐『新制中学国史 上級用』である。同年の文部省「中学校教授要目」改訂で初めて教授要目に挙がった（[[水口幹記-国風文化論の現在]]）。
- 吉川は、それ以前から「唐の影響を強く受けた文化から日本独特の文化へ変わった」という言説（〈古代文化変容論〉）があり、そこに国風文化という用語が張り付けられたと指摘する（同上）。
- 水口幹記は、国風文化が戦争へ向かう時代背景のもとで登場した「イデオロギー色の強い言葉」であったと述べる（同上）。
- 1950年代には「民族文化」の意味合いが加わり、1970・80年代には国風文化の時代にも中国文化の影響はなくなっていないとする論が登場した（同上）。

### 遣唐使「廃止」説との関係

- 遣唐使廃止説が否定されたことで、国風文化についても再考が必要になった（→[[遣唐使の停止]]）。
- 承和の遣唐使（838年派遣）以後も、新羅・唐の商人や渡航僧による交流は活発で、唐物はむしろ自由に流入していた（[[水口幹記-国風文化論の現在]]）。

## 諸説・論点

| 論者 | 主張 |
|---|---|
| 木村茂光（1997） | 外交・対外認識・儀式・文人貴族を含めた日本社会全体から国風文化の特質を論じた。以後の必読書とされる |
| 榎本淳一 | 民間交流の活発化で女性にも漢籍が届き女流文学が生まれたとし、国風文化を「日本における中国文化の一種の大衆化」ととらえ得るとする。純和風の文化という誤解を招く「国風文化」の名称には問題が多いとする |
| 西本昌弘（2015） | 平安前期を唐風一辺倒とする評価や10世紀以降の過度な和風強調を問題とし、「天暦・寛弘文化」の呼称を提唱 |
| 佐藤全敏（2017・2021） | 9世紀末以降、それ以前に受容した中国文化のうち最も根を下ろしたスタイルが浮上し、「倭のなかにあった文化」と並立・融合したと定義。唐物は「消費財」として影響は限定的とする |
| 関周一・久保智康・榎本淳一（2022） | 佐藤説が唐風・唐物を矮小化している、工芸史・思想史の成果を顧慮していない、などと批判 |
| 河上麻由子（2021） | 高麗・北部ベトナムとの比較から、唐滅亡後の周辺諸国でも国風文化的な現象が起きたことを示し、国内問題として捉えてきた国風文化を相対化 |

（以上、[[水口幹記-国風文化論の現在]]による研究史整理）

- 西本昌弘は、近年の研究動向が国風文化における「漢」と「和」のどちらを重視するかで大きく分かれていると指摘した（[[水口幹記-国風文化論の現在]]）。
