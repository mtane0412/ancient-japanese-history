# 埴輪

埴輪は、古墳の墳丘や周囲に立て並べられた素焼きの土製品であり、円筒形の円筒埴輪と、家・器財・動物・人物などをかたどった形象埴輪に大別される（[[神奈川県-埴輪の起源と神奈川県内出土の埴輪]]、[[堺市-百舌鳥古市古墳群提案書]]）。円筒埴輪は吉備地方の弥生墳丘墓の特殊器台に起源をもつとされる（[[岡山市埋蔵文化財センター-吉備の埴輪]]）。

## 詳細

### 起源: 特殊器台
- 岡山（吉備）の弥生墳丘墓で用いられた特殊器台が埴輪の祖型とされる（[[岡山市埋蔵文化財センター-吉備の埴輪]]）。
- 特殊器台は吉備が出土の中心で、立坂型・向木見型・宮山型・都月型に分類される。文様は交差文から弧帯文へと変遷する。その意味については、飲食物供献儀礼を象徴化したもの、主要な祭祀の道具などの見方がある（[[神奈川県-埴輪の起源と神奈川県内出土の埴輪]]。近藤義郎・春成秀爾「埴輪の起源」1967を参考文献に挙げる）。
- [[箸墓古墳]]は、吉備に起源をもつ特殊器台と都月型埴輪の型式変遷などから、最古の大型前方後円墳とされる（[[春成秀爾ほか-古墳出現期の炭素14年代測定]]）。

### 種類と出現時期（考古学的に確認されていること）
神奈川県の考古学講座資料は、出現年代を次のように整理している（[[神奈川県-埴輪の起源と神奈川県内出土の埴輪]]）。

| 種類 | 出現・使用の時期 |
|---|---|
| 円筒埴輪 | 3世紀後半〜 |
| 家形・器財埴輪 | 4世紀中頃〜 |
| 動物埴輪 | 4世紀中頃〜6世紀 |
| 人物埴輪 | 5世紀前半〜6世紀 |

- 古墳前期（3〜4世紀）の主体は円筒埴輪で、形象埴輪で最も早いのは家形であり、のちに蓋・盾・靫・甲冑・柵・囲・水鳥などが加わる。人物埴輪は中期（5世紀）に登場する（[[岡山市埋蔵文化財センター-吉備の埴輪]]）。

### 規模と生産
- 誉田御廟山古墳（[[応神天皇]]陵古墳）では、円筒埴輪が推定2万本立てられていたとされ、盾・靫・家・水鳥などの形象埴輪も出土している（[[羽曳野市-応神天皇陵古墳誉田御廟山古墳]]）。
- 岡山の造山古墳の埴輪には[[百舌鳥・古市古墳群]]の埴輪と似たものがあり、工人が地域間を往来したと考えられている（[[岡山市埋蔵文化財センター-吉備の埴輪]]）。
- [[今城塚古墳]]では、埴輪を生産した新池埴輪製作遺跡が併せて史跡に指定されている（[[文化遺産オンライン-今城塚古墳]]）。
- 国宝「埴輪 挂甲の武人」（群馬県太田市出土、6世紀、高さ130.4cm）は武装を細部まで表現しており、太田市周辺には同様の武人埴輪が数体あることから、埴輪作りの専門集団がいたと考えられている（[[文化遺産オンライン-埴輪挂甲の武人]]）。

## 諸説・論点

### 人物埴輪群像は何を表すか
人物埴輪の群像が表す場面については多くの説がある（[[日高慎-埴輪樹立からみた地域性と階層性]] による整理）。

| 説 | 主な論者 |
|---|---|
| 首長権（霊）継承儀礼 | 水野正好、橋本博文ら |
| 殯（もがり） | 和歌森太郎、若松良一ら |
| 葬列 | 後藤守一ら |
| 生前の顕彰 | 杉山晋作、和田晴吾 |
| 供養・墓前祭祀 | 高橋克壽、車崎正彦ら |
| 他界における王権祭儀 | 辰巳和弘 |
| 神宴儀礼 | 小林行雄、森田悌 |
| 死後の世界の近習 | 塚田良道 |

- 水野正好の首長権継承儀礼説は大嘗祭をモデルにしているが、大嘗祭の成立は新しいとする岡田精司の議論などが弱点として指摘されている（[[日高慎-埴輪樹立からみた地域性と階層性]]）。
- 日高慎は、埴輪が表す場面は一つではないとして、単一の場面に還元する説を否定する（[[日高慎-埴輪樹立からみた地域性と階層性]]）。
- 関東の6世紀代では、墳丘長約50m以上の古墳で人物埴輪が増える傾向があるとされ、埴輪の樹立に階層性がみられる（[[日高慎-埴輪樹立からみた地域性と階層性]]）。

### 殉死の代わりという伝承
- 『日本書紀』垂仁紀には、殉死の代わりに土物（埴輪）を立てたという起源伝承がある（Wiki未収録の一般知識）。考古学的には円筒埴輪は特殊器台に由来し、人物埴輪の出現は5世紀と新しいため、この伝承は埴輪の起源を説明するものとはみなされていない（起源と出現時期は上記の資料による）。
