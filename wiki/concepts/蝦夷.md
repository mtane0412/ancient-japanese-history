# 蝦夷

古代の中央政権（倭王権・律令国家）が、主に東北地方など東日本・北日本の、支配の外にあるとみなした人々を呼んだ名称（総論）。古くは「えみし」と読み、のちに「えびす」「えぞ」とも呼ばれた（[[福島県文化振興財団-蝦夷論の系譜と東北考古学]]）。国家の側が付けた呼称であり、その実態が異民族であったのかどうかは、長く議論されてきた。

## 呼称と国家の位置づけ（研究者の解釈）

- **化外の夷狄**: 石母田正（1963）は、天皇の統治が及ぶ「化内」に対し、「化外」を隣国（唐）・諸蕃（新羅など）・夷狄（蝦夷・隼人）に区別する「小帝国」構造が大宝律令制定時に成立したと論じた。永田一の学位論文の審査要旨は、一部修正を要するものの、蝦夷を「化外の夷狄」とみる見方は現在も有効だとする（[[法政大学-永田一学位論文要旨]]）。
- **認識の成立**: 永田一は、倭王権の東国進出の中で「ヒナ→アヅマ→エミシ世界」という概念が成立し、従った者は「東人」とされ、「蝦夷」という人間集団の認識は坂東が成立した7世紀前半頃に成立したと論じる（同上）。
- **『日本書紀』の蝦夷記事**: 永田一は、敏達天皇10年閏2月条以降の記事は実態を反映するが、それ以前は編者の造作か伝承であるとする（同上）。『日本書紀』は8世紀の編纂史料であり、蝦夷を服属させる物語には編纂時の国家観が反映している可能性がある。
- **「蝦狄」**: 永田一は、780年に渡嶋（北海道方面）の蝦狄の用例が現れ、渡嶋の実態が知られると「蝦狄」の表記は使われなくなったと論じる（同上）。

## 民族論の研究史

福島県文化振興財団に掲載された講演要旨（講演者は菊池徹夫と推定）は、研究史を次のように整理する（[[福島県文化振興財団-蝦夷論の系譜と東北考古学]]）。

- **アイヌ説**: 江戸〜明治期に確立した。1970年代には伊東信雄（1971）が蝦夷を「アイヌ系の人種と規定した」と述べ、山田秀三（1974）は地名研究から東北の蝦夷がアイヌ語族であったろうとするなど、再評価された。
- **非アイヌ説**: 戦後に主流となり、高橋富雄が体系化した。高橋（1979）は、蝦夷が「ほんとうに異民族であったのか。それとも内なる外国人の単なる観念疎外にすぎなかったのか」と問うた。
- **東北蝦夷非実在説（松本建速）**: 東北北部は縄文〜5世紀前半には北海道と同系統の文化であったが、7世紀以降は本州と同じ文化になり、その住民は移住者であったとする説として紹介されている（学界での評価は本資料からは不明）。

## 考古学からみた蝦夷

- 北海道の続縄文文化の北大式土器が、7世紀の阿倍比羅夫の北航の頃に仙台平野で集中して出土する。青森県猪ノ鼻遺跡では古墳時代前期の土師器と続縄文土器が共伴する（[[福島県文化振興財団-蝦夷論の系譜と東北考古学]]。考古学的事実）。
- 擦文文化・末期古墳など、7〜9世紀の東北北部・北海道の考古学的様相は、本 Wiki では資料未取り込みである。

## 律令国家の城柵と蝦夷（8世紀を中心に）

以下の年次は主に[[宮城県多賀城跡調査研究所-多賀城跡年表]]による（年表は二次的な整理であり、典拠の史料名は明記されていない）。

| 年 | 出来事 |
|---|---|
| 647・648年 | 渟足柵・磐舟柵を設置（越国） |
| 658〜660年 | 越国守阿倍比羅夫の北征 |
| 659年 | 遣唐使が道奥の蝦夷の男女2人を唐の天子に見せる（「伊吉連博徳書」。[[福島県文化振興財団-蝦夷論の系譜と東北考古学]]） |
| 720年（養老4年） | 陸奥国で蝦夷が蜂起し、按察使を殺害 |
| 724年（神亀元年） | [[多賀城]]を造営（陸奥国府・鎮守府） |
| 733年（天平5年） | 出羽柵を秋田村に移す（のちの秋田城） |
| 737年（天平9年） | 大野東人が陸奥・出羽の連絡路の建設を開始 |
| 760年（天平宝字4年） | 桃生城・雄勝城を造営 |
| 762年（天平宝字6年） | 多賀城碑を建立（碑文に「去蝦夷国界一百廿里」とある。[[福島県文化振興財団-蝦夷論の系譜と東北考古学]]） |
| 767年（神護景雲元年） | [[伊治城]]を造営（[[築館町教育委員会-伊治城跡現地説明会資料]]） |
| 774年（宝亀5年） | 海道蝦夷が蜂起し、桃生城が炎上 |
| 780年（宝亀11年） | 伊治呰麻呂の乱 |
| 786〜795年 | 胆沢の蝦夷を討つ |
| 801〜803年 | 坂上田村麻呂の征討、[[胆沢城]]（802）・志波城（803）を建設 |
| 805年（延暦24年） | 平安京造営と蝦夷征討を中止（徳政相論） |
| 812年頃 | 徳丹城を造営 |
| 878年（元慶2年） | 元慶の乱、秋田城が炎上 |

- **多賀城**: 創建年代（724年）は出土瓦で裏づけられ、8〜11世紀に機能した遺構は四期に編年される。瓦の文様の変遷による I〜IV 期の編年は、藤原朝獦による大規模改修、伊治呰麻呂の反乱（780年）、貞観地震（869年）による修築・再建に対応すると考えられている。⚠️ 文化遺産オンラインの解説は朝獦の改修を「726年」と表記するが、朝獦の改修を記す多賀城碑の建立が 762 年であることからみて、762 年の誤記である可能性がある（本 Wiki の推定。未確認）。出土品は 2024 年 8 月 27 日に重要文化財に指定された（[[宮城県多賀城跡調査研究所-多賀城跡年表]]、[[文化遺産オンライン-宮城県多賀城跡出土品]]）。
- **伊治城と伊治呰麻呂の乱**: 767年、律令政府は宮城県北部の支配強化と北上川中流域への進出の拠点として伊治城を建設した。これに伴う他地域からの移住に蝦夷側が反発した。780年、栗原郡の長官で蝦夷出身の伊治公呰麻呂が伊治城で反乱を起こし、按察使紀広純と牡鹿郡の長官道嶋大盾を殺害し、数日後に多賀城を占拠して略奪・放火した（[[築館町教育委員会-伊治城跡現地説明会資料]]）。伊治城と桃生城は、創建年が『続日本紀』に記される宮城県内の数少ない城柵である（同上）。
- 伊治城跡（国史跡）は、外郭の大溝・土塁、内郭の政庁、官衙ブロック、外側の竪穴住居群という三重構造をもつ。竪穴住居跡から青銅製の弩の機が出土し、国内で弩の実物が見つかった初例とされる（同上。考古学的事実）。

## 三十八年戦争

- 774年の海道蝦夷の蜂起から 811 年まで続いた律令国家と蝦夷の戦争を「三十八年戦争」と呼ぶ（呼称は[[法政大学-永田一学位論文要旨]]に見える。始点・終点の定義を示した資料は未取り込みで、811年の文室綿麻呂による征討終了を終点とする理解は未検証）。
- 780年の伊治呰麻呂の乱の後、律令政府は征討を強化し、阿弖流為らを降伏させるまで4回の大規模な遠征を行った（[[築館町教育委員会-伊治城跡現地説明会資料]]）。阿弖流為については[[アテルイ]]を参照。
- 永田一は、この戦争の終結を契機に、天皇の徳化を化外に及ぼそうとする意識が減退し、「閉じられた王土観」が形成されたと論じる（[[法政大学-永田一学位論文要旨]]）。
- ⚠️ 資料間の食い違い: 阿弖流為らの降伏を、[[築館町教育委員会-伊治城跡現地説明会資料]]は 801 年（延暦20年）とし、[[新井隆一-九世紀の城柵と北方社会]]は 802 年（延暦21年）の投降とする。
