# 城柵

城柵は、律令国家が[[蝦夷]]の居住する東北地方などに設けた、政治と軍事の拠点となる役所の施設である。「城」や「柵」と呼ばれた（[[大仙市-払田柵跡だより（城柵とは）]]）。外郭を築地塀や材木塀などで囲み、内部に政庁と官衙をもつ点が考古学的に確認されている（[[宮城県-多賀城跡の概要]]、[[高橋千晶-胆沢城跡]]）。

## 詳細

### 設置の流れ

[[宮城県多賀城跡調査研究所-多賀城跡年表]]による主な設置年は次のとおりである（年表は二次的整理で、史料名は明記されない）。

| 年 | 城柵 | 地域 |
|---|---|---|
| 647年 | [[渟足柵]] | 越国 |
| 648年 | [[磐舟柵]] | 越国 |
| 724年 | [[多賀城]]（陸奥国府・鎮守府） | 陸奥 |
| 733年 | 出羽柵を秋田村へ移す（のち秋田城） | 出羽 |
| 760年 | [[桃生城]]・雄勝城 | 陸奥・出羽 |
| 767年 | [[伊治城]] | 陸奥 |
| 802年 | [[胆沢城]]（鎮守府を移す） | 陸奥 |
| 803年 | [[志波城]] | 陸奥 |
| 812年頃 | 徳丹城 | 陸奥 |

### 機能（考古学的に確認されていること）

- 政治と軍事の拠点であり、秋田県内には秋田城・雄勝城・由理柵などが設けられ歴史書に記録される。払田柵のように記録の残らない城柵もある（[[大仙市-払田柵跡だより（城柵とは）]]）。
- 多賀城は陸奥国の国府で、奈良時代には鎮守府も置かれた（[[宮城県-多賀城跡の概要]]）。
- 伊治城は、外郭の大溝・土塁・門・櫓、内郭の政庁、官衙ブロック、外郭内の竪穴住居群という三重構造をもつ（[[築館町教育委員会-伊治城跡現地説明会資料]]、[[文化遺産オンライン-伊治城跡]]）。
- 胆沢城は、一辺約670mの正方形の築地とその内外の溝からなる外郭の内部に、政庁と複数の官衙域をもつ（[[高橋千晶-胆沢城跡]]）。

### 時期による性格の変化（研究者の解釈）

- 新井隆一は、805年の徳政相論で北への軍事侵攻が断念されたあとも胆沢城の重要性はむしろ増し、鎮守府の在庁に入り込んだ胆沢以北の蝦夷が城柵の存続を支えたと推定する（[[新井隆一-九世紀の城柵と北方社会]]）。城柵が軍事拠点から行政・交易の拠点へ性格を変えたとみる見方につながるが、これは著者の解釈である（[[胆沢城]]参照）。

## 諸説・論点

- 取り込んだ資料は個別の城柵の解説が中心で、城柵と郡の関係、柵戸の移配などの制度面は、本Wikiでは資料未取り込みである。加藤未知「律令国家の奥羽経営 城柵と柵戸」（2004、奈文研の全国遺跡報告総覧に書誌が登録）などが関連する研究だが、本文は未確認である。
- 「城柵」を蝦夷支配のための装置とする理解は一般的だが、城柵の周辺で蝦夷がどのように城柵を利用したかについての見方は、新井隆一のように分かれる余地がある。
