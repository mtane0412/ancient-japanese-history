# 青森県文化財保護課「小牧野遺跡」

## 書誌情報
- 青森県教育委員会文化財保護課の Web ページ（青森県の記念物・史跡の紹介）。更新日は取得時に確認できなかった。

## 要旨
史跡小牧野遺跡の指定年月日、調査の経緯、環状列石の構造、出土品を簡潔に説明する。

## 主要な主張
- 1989年、青森山田高校の葛西勵・高橋潤らの発掘で環状列石の構造が判明し、のち青森市教育委員会が調査・整備を引き継いだ。
- 環状列石は中央の組石を中心とする内帯・外帯の三重の輪で、一部は四重。最大径55m。斜面上に造成した地形を利用して配石している。
- 十腰内1式土器（大型壺形土器の土器棺、赤色切断壺形土器を含む）、三角形岩版、土偶、鐸形土製品などが出土。列石内の覆土から続縄文時代の土器が出土している。
- 1995年3月17日史跡指定、2001年8月13日追加指定。

## 疑問点・他資料との食い違い
- 公式サイト（[[縄文遺跡群公式サイト-伊勢堂岱・小牧野・大森勝山・鷲ノ木]]）は環状列石を「三重構造」とし、本資料は「一部四重」とする。観光庁の解説文は「3つの完全な環と1つの部分的な環」とし、本資料と整合する。
- 続縄文土器の型式や出土量は記載がない。
